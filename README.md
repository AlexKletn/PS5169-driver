# PS5169-driver

[Русская версия](README.ru.md)

[Contributing](CONTRIBUTING.md) · [GPL-2.0-only](LICENSE)

Rust workspace for the Parade PS5169 USB-C redriver. The driver will handle orientation and signal routing for USB 3 and DisplayPort Alt Mode. Board wiring and signal settings belong in the board project.

The `ps5169` crate is a placeholder for the chip driver.
