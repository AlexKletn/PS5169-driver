# PS5169-driver

[English version](README.md)

[Участие в проекте](CONTRIBUTING.ru.md) · [GPL-2.0-only](LICENSE)

Rust workspace для редрайвера Parade PS5169. Драйвер будет учитывать ориентацию разъёма USB-C и переключать линии USB 3 и DisplayPort Alt Mode. Разводка и настройки сигнала задаются в проекте платы.

Крейт `ps5169` пока служит заготовкой драйвера чипа.
