# PS5169-driver

[English version](README.md)

[Участие в проекте](CONTRIBUTING.ru.md) · [GPL-2.0-only](LICENSE)

Крейт `ps5169` проверяет идентификатор чипа, выполняет сброс и переключает линии USB 3 и DisplayPort. Крейт использует `no_std` и получает доступ к регистрам и настройки платы от вызывающего кода. Linux-адаптер регистрирует коммутатор ориентации Type-C и ретаймер для каждого привязанного I²C-устройства.

## Сборка модуля Linux

Используйте настроенное дерево сборки ядра с поддержкой Rust, Type-C и I²C. Ядро должно предоставлять Rust-интерфейс I²C-драйвера, функции SMBus и интерфейсы коммутатора и ретаймера Type-C.

```sh
make -C "$KERNEL_BUILD" M="$PWD/kernel" MO="$PWD/target/kernel" \
  PS5169_PROFILE="$PWD/profiles/tb371fc.toml" modules
```

## Настройки платы

Укажите `compatible = "parade,ps5169"` и стандартные свойства графа и коммутатора Type-C. Передайте путь к TOML-профилю через `PS5169_PROFILE` при сборке Cargo или Kbuild. [Профиль TB371FC](profiles/tb371fc.toml) задаёт упорядоченные пары «регистр и значение» для инициализации и переключения USB, DisplayPort и совмещённого режима. В таблице инициализации должен быть регистр эквализации USB RX `0x51`. После сна драйвер проверяет его значение и активный маршрут. Для генерации профиля нужен Python 3.11 или новее.

Необязательное свойство `parade,defer-id-timeout` преобразует тайм-аут чтения ID при привязке устройства в `EPROBE_DEFER`. Профиль TB371FC включает этот обход до выяснения зависимости запуска.

При отложенной привязке регистр ID и время до ошибки доступны в `/sys/kernel/debug/devices_deferred`. При успехе драйвер выводит общее время инициализации. Сообщение о сбросе содержит заданную и фактическую длительность паузы.
