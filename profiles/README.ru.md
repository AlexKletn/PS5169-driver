# Профили регистров PS5169

[English version](README.md)

[Профиль TB371FC](tb371fc.toml) содержит последовательности регистров из оригинального драйвера Lenovo. USB 3 и DisplayPort проверены на TB371FC. Я не могу быть уверен, что та же инициализация, эквализация и последовательности переключения подойдут любой плате с PS5169. Для каждой платы можно выбрать профиль, проверенный на её железе, через `PS5169_PROFILE`. В проекте TB371FC копия профиля хранится рядом с разводкой USB.
